Política de Privacidade

Última atualização: 28 de setembro de 2026

Esta página explica que dados pessoais o BIO-OX Protocolo recolhe quando usa este assistente, para que servem, com quem são partilhados e quais são os seus direitos.

1. Quem é o responsável pelo tratamento dos dados

Nuno Andrade, operando sob a marca BIO-OX.
Contacto: nunocandrade@gmail.com
WhatsApp: +351 918 977 205

2. Que dados recolhemos

  • Dados que indica no formulário: nome, idade, país e email.
  • Respostas ao questionário de Score de Stress Oxidativo, e as queixas respiratórias que seleciona.
  • Mensagens que escreve na conversa com o assistente, incluindo qualquer informação de saúde que decida partilhar.
  • Dados técnicos de utilização: em que ponto da conversa está (ex: iniciou o chat, viu o resultado, clicou em falar no WhatsApp), para percebermos onde as pessoas têm mais dúvidas.

3. Para que usamos estes dados

  • Calcular e mostrar-lhe o seu Score de Stress Oxidativo.
  • Gerar as respostas do assistente de conversação, personalizadas ao que partilha.
  • Contactá-lo, se pedir, para falar sobre consultadoria ou suplementação.
  • Melhorar o funcionamento do assistente.

Não vendemos nem partilhamos os seus dados para publicidade de terceiros.

4. Com quem partilhamos os dados

Para o assistente funcionar, os seus dados passam por estes prestadores de serviços, apenas para o efeito técnico de o fazer funcionar:

  • Supabase (alojamento de base de dados, servidor na União Europeia) — guarda o seu nome, email, idade, país, score e queixas.
  • Anthropic (fornecedor da inteligência artificial que gera as respostas do assistente, sediado nos EUA) — recebe as mensagens da conversa para gerar cada resposta. A Anthropic não usa estas conversas para treinar os seus modelos.
  • GitHub Pages — aloja esta página web.

5. Dados de saúde

Se partilhar informação sobre a sua saúde na conversa (sintomas, diagnósticos, condições), isso é considerado uma categoria especial de dados ao abrigo do RGPD. Ao marcar a casa de consentimento antes de iniciar o score, está a autorizar expressamente este tratamento, exclusivamente para lhe dar uma resposta personalizada. Pode retirar este consentimento a qualquer momento, pedindo a eliminação dos seus dados (ver ponto 7).

6. Quanto tempo guardamos os dados

Guardamos os seus dados enquanto forem necessários para lhe podermos responder e dar seguimento ao seu pedido, ou até nos pedir para os eliminar.

7. Os seus direitos

Pode, a qualquer momento, pedir-nos por email:

  • Aceder aos dados que temos sobre si;
  • Corrigir dados incorretos;
  • Eliminar os seus dados;
  • Retirar o consentimento dado;
  • Receber uma cópia dos seus dados num formato portátil.

Basta escrever para nunocandrade@gmail.com. Também tem o direito de apresentar reclamação junto da CNPD (Comissão Nacional de Proteção de Dados).

8. Cookies

Este assistente não usa cookies de publicidade ou de rastreio de terceiros.

9. Alterações a esta política

Podemos atualizar esta página ocasionalmente. A data no topo indica a versão mais recente.
